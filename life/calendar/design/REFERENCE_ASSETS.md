# Reference assets

life-flow-wallpaper.webp: generated with the built-in image tool from the supplied second reference as a style reference. Source generated PNG retained separately. Production wallpaper contains no text, time marks, cards, device frame or controls. It is embedded offline, independently from UI.

Prompt: recreate the pale pearl-white glass background of the left YOS screen, icy sky-blue upper/lower left, subtle lavender center, warm ivory bottom right and quiet translucent mint organic form at upper right; nearly-white readable center. Full bleed flat portrait background only; no phone, UI, icons, numbers, cards or hands.

Phosphor duotone icons: official phosphor-icons/core, commit2b75f3ad12b420c9504ef05df8d2564a28f8500e, MIT. Exact SVG source is stored in phosphor-icons.json; license in PHOSPHOR_LICENSE.txt. Used offline with currentColor, no CDN.

mineral.webp, graphite.webp, matte.webp: encoding conversions of the existing Canva exports at their original pixel dimensions. PNG originals retained unchanged.
