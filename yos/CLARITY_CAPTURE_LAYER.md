# Clarity capture layer

ClarityはMY WAYの6番目の領域や独立した主役ページではない。思いつき、気づき、音声・メモを、整理前のまま最速で受け取る入力層として扱う。

## 入口

- Home: 「気づきを残す」。今やることを見ている途中でも入力できる。
- Life: 「気づきを残す」。暮らしの記録とは分け、整理前の内容を受け取る。
- Idea: 「クイック入力」。端末だけのメモと、YOSが後から整理する入力を区別する。
- 主要5領域の下部ナビにはClarityを追加しない。

## 保存と整理

1. Clarityは原文を先に保存する。
2. YOSは原文を消さず、根拠と不明点を保ったまま整理する。
3. 内容に応じて、Homeのタスク、Ideaのアイデア、必要な場合のみLife / Money / Hero’s Journeyの候補へ振り分ける。
4. 自動振り分けは確定操作ではない。本人が確認できる候補として返す。

## 境界

- Ideaの「この端末だけに保存」はローカルメモであり、Clarity経由の正式な入力とは区別する。
- 既存の保存キー、Lifeの日次データ、Hero’s Journeyの記録を移行・削除しない。
- YOSの正式名称、人格、チャットの識別を変更しない。
- 最新VisualをYOS／ようすけが承認するまでDraftを維持し、統合しない。
- 自動確認の証拠は必ず現在のPR先頭から取得する。
