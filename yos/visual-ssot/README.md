# MY WAY by YOS Visual SSOT

The product visual source of truth for this implementation is:

- `my-way-five-domains-roadmap-final.jpeg`
- Japanese title: `MY WAY by YOS 5領域＋37歳の逆襲ロードマップ最終磨き込み版`
- received from YOS on 2026-08-28 for Issue #272

The image controls layout, information hierarchy, screen density, surface
relationships, color, motifs, and the distinct composition of Home, Life,
Money, Hero's Journey, and Idea. Values pictured inside the image are layout
samples only. The product must render existing local data or its established
empty states; the pictured amounts, dates, plans, habits, levels, experience,
and roadmap examples must not be hard-coded as product data.

The JPEG is committed with the implementation so the pull request and Issue
#272 can point to an immutable comparison target.
