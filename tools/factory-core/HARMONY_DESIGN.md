# YOS Harmony Design Contract

## Theme
共通テーマは **調和**。

## Goal
すべての画面を同じ見た目に固定しない。
役割ごとの違いを許容しながら、同じ世界の製品に見えることを優先する。

## Shared principles
- 太陽・自然・穏やかさ・見やすさを基調にする
- 生成り系の背景、深い紺系の文字、太陽ゴールド、空・若葉・夕焼け系の補助色を使う
- 角丸、余白、影、文字階層、情報密度、アニメーションの温度感を揃える
- iPhoneで毎日使うことを優先し、装飾のための装飾は避ける
- 機能ごとの個性は許可するが、操作体系と視覚言語は連続させる
- 「全部同じ」ではなく「違っていても調和している」を完成条件にする

## Placement rule
- MY WAY / Clarity / Money / Life / Idea / Hero’s Journey / MY REMOTE は利用者向け機能
- One Enter / Factory Core / ProjectY HQ / Mission Control は開発・基盤側
- 開発基盤は通常利用画面で主役にしない

## Review gate
新規画面・改修画面は、機能テストとは別に「Harmony review」を通す。
