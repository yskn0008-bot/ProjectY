# PROT Factory Web v0.1

Isolated iPhone-first front-end prototype for the existing PROT Factory.

## Purpose
Let the owner describe a desired app/automation in natural Japanese without manually navigating development lanes.

## v0.1
- single natural-language intake
- local deterministic preview routing: inventory / shortcut / web
- no network calls
- no secrets
- no production writes
- no changes to existing PROT Factory
- intentionally does not claim to manufacture or install anything yet

## Verification
Open index.html in a browser. Test blank input, iPhone automation request, Web app request, and reuse request.

## Rollback
Delete this prototype directory/branch. No existing production asset is modified.
