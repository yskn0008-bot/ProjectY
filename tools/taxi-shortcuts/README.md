# YOS TAXI｜運行ショートカット（安全優先初版）

新たな管理システムやScriptableを作らず、既存のYOS Taxi Webアプリを開くiPhone標準ショートカット2本。

- **YOS TAXI 運行**：出庫（本人確認）、営業画面、M100、20分休憩タイマー（休憩の記録はしない）、帰庫（本人確認）、日報写真選択画面。
- **YOS TAXI 降車**：ロック画面・ホーム画面の両方から同じショートカットを実行する。タップ時刻とランダムな受付IDをWebアプリへ渡す。

## 確定した安全設計

- **元のClarity Inbox.txt、NotionのYOS Inbox、既存Scriptableやショートカットのデータには書き込まない。**
- Webアプリで営業中が確認できない場合、降車記録をしない。新しい営業を自動的に開始することもしない。記録成功の場合だけWebアプリ内に保存する。
- タップ時刻は日本時間で渡す。3分以上経過・無効なID・同じ受付ID・4秒以内の二重タップは追加記録しない。URLのリロード・戻る操作による再登録も防止する。
- **Safariとホーム画面に追加したPWAのローカル保存領域は別々になる場合がある。** このショートカットはSafariで開くことがあり、PWAに保存した乗務記録とは自動同期しない。別領域には営業中記録がないため、保存せず停止する。
- 走行中の操作は行わない。ロック画面からの起動はiOSによる解錠が必要な場合がある。
- 売上や手書き日報のOCR・Notion照合は未接続。既存の降車ボタンとバックアップは保持。

## iPhoneでの使用（実機検証が必要）

1. 署名済みの「YOS TAXI 運行.shortcut」「YOS TAXI 降車.shortcut」をiPhoneの「ショートカット」に登録する。両方とも既存の同名資産との衝突がないことを確認する。
2. **次回の新しい営業日**に、「YOS TAXI 運行」→「出庫」でSafari側に営業開始を確認する。PWA等の旧記録を消さない。既に出庫済みの勤務で保存先を切り替えない。
3. 安全な停車中に「YOS TAXI 降車」を1回起動し、同じSafari側のYOS TAXI履歴に正しい時刻が1件だけ反映されるか確認する。「記録していません」と表示されたら以後の使用を止める。
4. 一致したらロック画面でカスタマイズ→下部コントロール→ショートカット→「YOS TAXI 降車」を指定する。ホーム画面はショートカットウィジェットまたはショートカットの「ホーム画面に追加」で同じショートカットを選ぶ。
5. 実機のロック解除要件、2回押しの結果、Safari/PWA別の表示差を確認する。**実機検証完了までは元のWebアプリ内「降車を記録」を継続**。

## 復旧・境界

ショートカットを外すだけで旧運用に戻せる。Webアプリの既存ローカルストレージ、Clarityファイル、Notion原本は削除しない。iPhoneの登録・配置はAppleの端末操作が必要。
