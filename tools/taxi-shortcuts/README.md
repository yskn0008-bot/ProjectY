# YOS TAXI｜運行ショートカット（検証用初版）

二本だけを使用し、既存のYOS Taxiに接続する。

- **YOS TAXI 運行**：出庫（本人確認）、営業画面、M100、休憩20分タイマー（記録なし）、帰庫（本人確認）、日報写真。
- **YOS TAXI 降車**：ロック画面・ホーム画面の両方で同一のショートカットを使用。タップ時刻と毎回異なる操作IDを現在のYOS TAXI Web UIへ渡す。

## 安全と互換性

- ブラウザ側で「営業中」が確認できなければ降車記録しない。URLタップ時刻を基準に保存する。3分経過した操作・不正な操作ID・重複IDは保存しない。
- Safariとホーム画面に追加したPWAはiOS上で保存領域が別になる場合がある。**出庫も降車も、同じショートカットの入口から行う**。ユーザーのiPhoneで実データを確認するまで「ロック画面からの記録が元のPWAと同期」とはみなさない。
- Shift開始と終了には既存の確認ダイアログを使用する。日報写真は従来の選択ボタンへ誘導するだけ。Notionへの自動照合は未実装。休憩タイマーも休憩実績を記録しない。
- 走行中の操作は禁止。ロック中はiOSが解錠を要求する場合がある。
- 従来のYOS Taxiの保存キー・イベント・旧版・Notion正本はそのまま保護。

## iPhone導入

1. GitHub Actions の「Taxi native Shortcuts build」で署名済みの \`YOS TAXI 運行.shortcut\` と \`YOS TAXI 降車.shortcut\` を取得する。HubSignによる署名が成功したものだけを配布する。
2. 「YOS TAXI 運行」の出庫から、営業開始の本人確認を実行する。
3. 同じブラウザ保存先で「YOS TAXI 降車」を1回起動し、**履歴に正しい時刻が1件だけ表示されるか**確認する。
4. 問題がなければロック画面のショートカット用コントロール/ウィジェット、ホーム画面のショートカットウィジェットで同じ「YOS TAXI 降車」を選ぶ。
5. iOS/ロック状態によっては解錠が必要。Safari・PWAで異なる件数が表示されたらそこで停止し、保存先の統合を検証する。

## 復旧

記録の消去や上書きは行わない。ショートカットだけ外せば従来のWebアプリ内ボタンは継続使用できる。ブラウザのローカルデータを削除しない。
