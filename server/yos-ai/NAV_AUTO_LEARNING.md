# YOSナビ 自動学習 v35

## 目的

Project75の`乗車履歴`へ日報が追加された後、YOSナビの期待値モデルをコード変更なしで更新する。

## データフロー

```text
Project75 乗車履歴
  ↓ 読み取り専用
Vercel /api/yos/nav-model
  ↓ 個別明細を除いた集計モデルのみ
YOSナビ
  ↓
時間帯・曜日・現在地に応じた候補順位
```

## 学習対象

- 営業日
- 乗車時刻
- 乗車地
- 降車地
- 売上

時刻または乗車地に`?`・`？`がある明細、乗車地が不明な明細、エリア分類できない明細は学習対象外とする。

## 評価式

- 需要 45％
- 平均単価 25％
- 次の実車への連鎖 20％
- 回転 10％

月〜木／金〜日、14–18時／18–20時／20–22時／22–24時／0–2時／2–5時でモデルを分ける。

## 更新頻度

- APIサーバー：標準15分キャッシュ
- YOSナビ：起動時、復帰時、15分ごとに確認
- 手動の「学習更新」ボタン：APIキャッシュを強制更新
- 通信失敗時：端末内の前回モデルを最大7日使用
- 前回モデルもない場合：内蔵モデルへ安全に戻る

## 公開する情報

APIはエリア別件数・平均単価・中央値・連鎖率・スコアだけを返す。
個別の営業日、乗車時刻、乗車地、降車地、支払方法などの明細は返さない。

## 本番接続

既存のYOS AI用Vercelプロジェクトを使用する。

1. Root Directoryを`server/yos-ai`にする。
2. `.env.example`記載のGoogle Workload Identity Federation設定を行う。
3. `PROJECT75_SPREADSHEET_ID`を設定する。
4. `YOS_ALLOWED_ORIGINS`へYOSナビの正確なHTTPS Originを設定する。
5. 読み取り専用サービスアカウントへProject75を共有する。
6. `GET /api/yos/nav-model`がモデルJSONを返すことを確認する。
7. 初回だけYOSナビを次の形式で開き、API URLを端末へ保存する。

```text
https://<YOSナビURL>/?modelApi=https://<Vercelドメイン>/api/yos/nav-model
```

以降はURL入力不要で自動学習する。

## 完了条件

- APIがProject75の最新営業日を返す
- YOSナビに「自動学習」と表示される
- 日報追加後に件数とモデル期間が自動更新される
- API停止時も前回モデルまたは内蔵モデルでナビが動く
- iPhone Safari／PWAで表示・Googleマップ遷移を確認する
