# YOS Health Automation｜水分通知専用

本人の最新方針（2026-11-19）：健康・食事・体重・美容の相談は既存Clarityへ直接行う。JOURNALはHealthの自動化に含めない。これらを開くショートカット・メニューは設けない。

本実装は既存Scriptableの `YOS Health Automation` を更新するもの。名称・配布先は維持し、既存 `YOS Common Installer` を再利用する。

## 実装範囲
- 起床側引数 `wake` または `sleep_off`：実行後2・5・8・11時間の4件の無音「水分補給の目安」通知を予約
- 就寝側引数 `sleep` または `sleep_on`：未配信の自分の通知4件だけを取り消す
- 単独起動（引数なし）のメニューは「水分通知を設定／止める」の2操作のみ
- 専用通知ID `yos.health.water.awake.1..4` のみ操作。既存の他の通知は触らない
- 多重起動時は同一通知IDを入れ直し、途中失敗時は自分の予約だけを取り消して安全停止
- 認証情報・健康データの外部送信、ClarityやJOURNALへの画面遷移、独自のDB追加は行わない

## iPhoneのオートメーション設定（未検証）
1. 既存Scriptableの `YOS Common Installer` で `YOS Health Automation` を導入・更新する
2. ショートカット → オートメーション → ＋ → 睡眠集中モードON → Scriptable「スクリプトを実行」で本スクリプトに引数 `sleep` を渡す
3. 同様に睡眠集中モードOFF → 本スクリプトに引数 `wake` を渡す
4. Scriptableの通知許可・Focus ON/OFFの自動実行可否・ロック中の通知配信・取消を実機で確認する
5. おやすみ／おはようでのSleep Cycle計測開始・終了は**この水分通知スクリプトの実装対象外**。別の既存連携で検証する

## 関連機能との境界
- Clarity：健康・食事・外見の相談窓口として直接利用。本スクリプトからは起動しない
- JOURNAL：本スクリプトには含めない
- Morning Brief・体重・Appleヘルスケア・Sleep Cycle：本スクリプトから呼び出さず、既存機能を保護する
- 水分補給量は個人差がある。医師から水分制限を指示されている場合はそれを優先し、定量の強制をしない
