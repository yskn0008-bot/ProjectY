# YOS Health Automation｜Scriptable bridge（初期実装）

既存の `YOS Common Installer` による配布を前提とする。正式名称は `YOS Health Automation`。
既存 `Clarity.Voice` / `Morning Brief` / `YOS JOURNAL` / Sleep Cycle は変更しない。

## 実装済み（コード）
- 引数 `wake`：起床（睡眠集中モードOFF）から2、5、8、11時間後の4回、無音で水分補給を促すローカル通知を予約する。
- 引数 `sleep`：睡眠集中モードON時、上記4件の未配信通知だけを取り消す。
- 専用ID `yos.health.water.awake.1..4` のみ操作し、他のScriptable通知は保持する。
- 無引数の手動起動：既存Clarity.Voice、公開JOURNAL、水分通知の予約/取消メニュー。
- 二重実行は同じ通知IDを入れ替える。通知の一部だけ予約して失敗した場合は専用通知4件を取り消して終了する。
- 体重・睡眠・食事・Notionの個人情報は外部送信・保存しない。

## iPhoneでの必要な設定（完成前）
1. 本スクリプトが共通インストーラーで配布されたら、既存インストーラーから正式名「YOS Health Automation」を導入。
2. ショートカット → オートメーション → ＋ →「睡眠（集中モード）」が**オン**→「すぐに実行」→「Scriptableのスクリプトを実行」にこのスクリプトを選択し、テキスト引数 `sleep` を渡す。
3. 同様に睡眠が**オフ**→「すぐに実行」→本スクリプトへ引数 `wake`。
4. オフ側の同一オートメーションに既存「ショートカットを実行：Morning Brief」、最後に「URLを開く：https://yskn0008-bot.github.io/ProjectY/journal-v2/」を追加する。朝刊を強制表示したくない場合は通知のみへ変更する。
5. Sleep Cycleの「計測開始」「停止」アクションがショートカット内で確認できる場合のみ、同一オートメーションへ追加する。**Siriで音声起動できる事実は、集中モードで無人自動起動できる証拠ではない**。現時点では開始/停止の完全自動化は未確認で、アクションがなければ手動のまま。
6. iOSの通知許可・集中モード・ロック中のアプリ遷移を実機確認する。

## 食事と体重
- 食事相談は既存Clarityを入口にして、健康・肌・体型・費用・好みから提案する。実際の食事の自動決定・栄養素推定・カロミル同期は未実装。
- 体重はAppleヘルスケアを原本とし、iOSショートカット標準「入力を要求（数値）」→「ヘルスケアサンプルを記録（体重）」を追加できる。Scriptableは直接HealthKitへ書かない。
- 水分量は医療上の水分制限を優先し、固定量や過剰摂取を指示しない。

## 完成判定
Node構文・模擬テストはiPhone動作の証明ではない。Sleep Cycleの操作、起床Focusオートメーション、Morning Brief、JOURNAL、通知到達、健康データ連携は実機未確認。
