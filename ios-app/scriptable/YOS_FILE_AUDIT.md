# YOS ファイル調査｜iCloud Driveの読み取り専用棚卸し

既存 YOS Common Installer に配布対象 file-audit として追加する。
正式名は「YOS ファイル調査」。新しいインストーラーやNotion DBを作らない。

## 安全性
- iPhoneの本人が明示的に選んだ1フォルダだけを、下位フォルダまで走査する。
- ファイル名・相対パス・拡張子・容量のみ。本文や画像本体は読まない。
- ファイルの作成・移動・削除・上書きなし。ネット送信なし。ChatGPTへの共有は本人が明示的に選択する。
- 同名・同容量は単に重複候補。内容の一致は確認していないため削除根拠ではない。
- 2,500件／深さ12階層／最大約70,000文字。上限・権限エラーは結果に明示する。
- アプリ管理のShortcuts、ScriptableやYOS関連フォルダは移動せず保護する。

## 初回調査（Siri設定なしで利用）
1. 本PRがmainへ統合された後、Scriptableで既存「YOS Common Installer」を開き、「YOS ファイル調査」を選択。
2. Scriptable「YOS ファイル調査」を起動。調査したいiCloud Driveフォルダを選択する。
3. 調査結果で「ChatGPTへ共有」を選び、このチャットへ渡す。選んだフォルダ以外は調査対象外。

## Siriから繰り返し実行する設定
Scriptable公式仕様では、Siri／ショートカットで外部フォルダを継続して読むには、Scriptableの「Create File Bookmark」ショートカットアクションで許可を作成する必要がある。Scriptable設定内だけで作成したブックマークはSiriでは使えない。

1. Apple「ショートカット」アプリでScriptableの「Create File Bookmark」を一度実行し、対象フォルダの許可を作成する。名前は厳密に「YOS Files Root」。
2. 「ショートカット」で新規ショートカットの名前を「ファイル調査」とし、Scriptableの「Run Script」アクションを追加。対象は「YOS ファイル調査」。
3. 必要なら「結果を表示」または「クリップボードにコピー」を後ろに追加し、Siriへ「ファイル調査」と呼びかける。

iCloud Drive直下を許可できるか、Scriptableのファイルプロバイダー権限はiPhone実機確認が必要。初回のフォルダ選択・権限承認・Siriショートカット登録をGitHubから自動完了させることはできない。

## 完了条件
- コードと共通配布カタログのハッシュが一致する
- Nodeモックテストで読み取り専用・Siri許可なしの安全停止・フォルダ選択・エラー表示を確認する
- iPhoneで実際にフォルダを取得し、ChatGPT共有とSiri起動を検証する
- iPhone実機が未検証の間は「完成」としない
