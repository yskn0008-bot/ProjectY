# YOSナビ v106 旧世代キャッシュ整理の安全記録

## 目的

YOSナビのService Workerが、現行キャッシュに加えて検証済みの直前世代を最大1件だけ保持し、壊れた旧世代や不要な古い世代を整理するときに、担当外PWAのキャッシュや利用中画面の配信先へ影響しない既存条件を回帰テストとして固定する。

## 変更範囲

- `nav/tests/retained-cache-cleanup-safety.test.mjs`
- 本記録ファイル

製品コード、Service Worker本体、画面、地図、現在地取得、期待値計算、営業判断、外部ナビ遷移は変更しない。

Taxi、Life、YOS、DB、乗車履歴、同期API、server、共通機能は変更しない。

## 固定する安全条件

1. 旧世代候補はYOSナビ専用`CACHE_PREFIX`に一致し、現行未満の世代番号を持つものだけに限定する。
2. 候補を新しい順に検証し、全重要資産が有効な最初の1世代だけを保持対象にする。
3. 整理時は現行キャッシュと保持対象の旧1世代を削除しない。
4. YOSナビ専用prefixに一致しない担当外キャッシュを削除しない。
5. 画面単位の配信先記録は、現行、保持旧世代、ネットワーク固定だけを残し、一括消去しない。
6. 整理処理からlocalStorage、sessionStorage、IndexedDB、担当外機能、外部遷移へ介入しない。

## 確認方法

GitHub Actions `YOSナビ Safety` と `Codex governance` で次を確認する。

- 新規回帰テストを含む全YOSナビ安全テストが成功すること
- 変更が`/nav/`内のテストと記録だけであること
- 未解決レビューと競合がないこと

## 未確認事項

- iPhone SE3 SafariでService Worker更新後も、現行キャッシュが不完全な場合に検証済み旧世代へ安全に戻れること
- ホーム画面PWAとSafariタブが異なる世代を利用中でも、利用中の保持対象が早期削除されないこと
- Vercel/CDN更新境界で壊れた旧世代が保持対象に選ばれないこと
- 公開環境でTaxi、Life、YOSなど担当外PWAのCache Storageへ影響しないこと
