# YOSナビ v106 保持キャッシュ検証の安全記録

## 目的

YOSナビが現行キャッシュを利用できない場合でも、候補となる旧世代キャッシュを世代番号と全重要資産の完全性で検証し、不正・欠損・読取不能なキャッシュを画面配信へ採用しない既存条件を回帰テストとして固定する。

## 変更範囲

- `nav/tests/retained-cache-validation-safety.test.mjs`
- 本記録ファイル

製品コード、Service Worker本体、画面、地図、現在地取得、期待値計算、営業判断、外部ナビ遷移は変更しない。

Taxi、Life、YOS、DB、乗車履歴、同期API、server、共通機能は変更しない。

## 固定する安全条件

1. 保持候補はYOSナビの有効な世代番号を取得できる場合だけ検証する。
2. 候補キャッシュを開き、`CRITICAL_ASSETS`の全件を候補自身の世代番号で検証する。
3. 重要資産が1件でも欠損・不正・別世代・読取不能なら候補を拒否する。
4. 検証処理の例外は安全側で`false`へ収束させ、画面や外部へ内部詳細を公開しない。
5. 画面の優先候補も同じ完全性検証を通過した場合だけ採用する。
6. 優先候補が無効なら現行キャッシュの完成状態を確認し、それも無効なら検証済み旧世代だけを選ぶ。
7. 検証処理からキャッシュ内容の追加・更新・削除、永続データ、外部遷移、担当外機能へ介入しない。

## 確認方法

GitHub Actions `YOSナビ Safety` と `Codex governance` で次を確認する。

- 新規回帰テストを含む全YOSナビ安全テストが成功すること
- 変更が`/nav/`内のテストと記録だけであること
- 未解決レビューと競合がないこと
