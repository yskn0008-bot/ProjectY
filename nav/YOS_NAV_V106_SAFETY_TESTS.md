# YOSナビ v106 安全回帰テスト

## 目的

YOSナビの次の機能変更へ進む前に、v97〜v106で追加したService Workerの安全条件を自動検査できる状態にする。

今回の工程では実行時コードを変更しない。既存のYOSナビをそのまま維持し、将来の変更で世代混在防止、旧キャッシュ退避、オフライン完全性検査、復旧処理が意図せず失われることを防ぐ。

## 追加ファイル

- `nav/tests/service-worker-v106-safety.test.mjs`
- `nav/YOS_NAV_V106_SAFETY_TESTS.md`

## 検査対象

1. Service Workerとキャッシュのv106世代識別子
2. 必須資産の完全性確認後にのみService Workerを有効化する順序
3. 現行より古い完全なキャッシュだけを退避対象にする条件
4. 同一画面の表示元をキャッシュまたはネットワークへ固定する処理
5. ネットワーク版HTMLと承認済みJavaScriptの世代固定
6. 古いネットワークマーカーを通常資産へ迂回させない処理
7. `sessionStorage`による再読込ループ防止
8. 承認済み資産以外をYOSナビ専用キャッシュ経路へ混入させない条件

## 実行方法

リポジトリのルートで次を実行する。

```bash
node --test nav/tests/service-worker-v106-safety.test.mjs
```

Node.js標準の`node:test`だけを使用し、追加パッケージは不要。

## 変更範囲

`/nav/`内のテストと記録ファイルのみ。以下は変更していない。

- YOSの正式名称、唯一の人格・司令塔としての役割
- `nav/service-worker.js`の実行時処理
- YOSナビの画面、地図、現在地取得、期待値計算、営業判断
- `/taxi/`、`/life/`、DB、同期API、乗車履歴

## 確認結果

- テストはNode.js標準モジュールだけで構成
- 実行時コードへの変更なし
- 担当範囲は`/nav/`のみ
- テスト内の正式名称はすべて「YOS」または「YOSナビ」を維持

## 未確認事項

- GitHub ActionsまたはローカルNode.js環境での実行結果
- iPhone SE3でのv106実機挙動
- 公開環境へのデプロイ反映

この工程は公開画面の動作を変更しないため、実機確認前でも既存機能への影響はない。
