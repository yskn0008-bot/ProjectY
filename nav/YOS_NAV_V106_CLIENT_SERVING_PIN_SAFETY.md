# YOSナビ v106 画面別配信先固定の安全記録

## 目的

YOSナビの更新中に、開いている画面ごとのHTMLとJavaScriptが異なる世代へ混在しないよう、既存の画面別配信先固定と安全な整理条件を回帰テストで固定する。

## 変更内容

- `nav/tests/client-serving-pin-safety.test.mjs`を追加
- ナビゲーションでは`resultingClientId`を優先し、既存画面では`clientId`を使う条件を固定
- 画面ごとの配信先を`CLIENT_SERVING_CACHES`で分離する条件を固定
- HTMLと承認済みJavaScriptを同じ画面の同じ配信先へ固定する条件を固定
- 現在存在しない画面の固定情報だけを削除する条件を固定
- キャッシュ整理後も現行、直前の有効な退避、ネットワーク固定だけを保持する条件を固定
- Taxi、Life、YOSの担当外パスを直接処理しない条件を固定

## 変更範囲

- `/nav/`内のテストと記録のみ
- YOSナビの実行時コード、画面、地図、現在地取得、期待値計算、営業判断、外部ナビ遷移は変更しない
- Taxi、Life、YOS、DB、乗車履歴、同期API、共通機能は変更しない

## 確認方法

GitHub Actions「YOSナビ Safety」で以下を確認する。

- 新規テストのJavaScript構文
- 既存YOSナビ安全回帰テストとの同時実行
- 画面ごとのclientIdによる配信先分離
- HTMLと承認済み資産の配信世代一致
- 終了した画面だけを固定情報から削除
- 現行・直前有効・ネットワーク固定の保持
- 担当外パスへ依存しないこと

## 未確認事項

- GitHub Actions「YOSナビ Safety」の結果
- Codex governanceの結果
- iPhone SE3 Safariで更新前後の複数タブを同時に開いた場合の世代分離
- ホーム画面PWAとSafariタブを同時利用した場合の配信先固定
- main反映後の再検査
