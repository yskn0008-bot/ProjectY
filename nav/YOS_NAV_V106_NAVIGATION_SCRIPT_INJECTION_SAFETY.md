# YOSナビ v106 必須スクリプト注入の安全記録

## 目的

YOSナビのHTMLが一部欠損した場合に既存の必須JavaScriptを安全に補完しつつ、重複読込、不完全なHTML、マーカー付与漏れを配信しない条件を回帰テストで固定する。

## 変更内容

- `nav/tests/navigation-script-injection-safety.test.mjs`を追加
- 必須スクリプトの重複を注入前に拒否する条件を固定
- 不足がある場合は`body`終了タグを持つHTMLだけへ注入する条件を固定
- 注入後に不足と重複を再検査する条件を固定
- 全必須スクリプトへネットワーク配信マーカーを付与できた場合だけHTMLを返す条件を固定
- Taxi、Life、YOS、serverの担当外パスへ依存しない条件を固定

## 変更範囲

- `/nav/`内のテストと記録のみ
- YOSナビの実行時コード、画面、地図、現在地取得、期待値計算、営業判断、外部ナビ遷移は変更しない
- Taxi、Life、YOS、DB、乗車履歴、同期API、server、共通機能は変更しない

## 確認方法

GitHub Actions「YOSナビ Safety」で以下を確認する。

- 新規テストのJavaScript構文
- 必須スクリプト重複の注入前拒否
- `body`終了タグ欠損時の注入中止
- 注入後の不足・重複再検査
- 全必須スクリプトへのネットワーク配信マーカー付与
- 既存YOSナビ安全回帰テストとの同時成功

## 未確認事項

- GitHub Actions「YOSナビ Safety」の結果
- Codex governanceの結果
- PRの競合・レビュー状態
- iPhone SE3 SafariでHTML資産が部分欠損した場合の実機挙動
- Vercel/CDNでHTMLとJavaScriptの更新境界がずれた場合の復旧挙動
- main反映後の再検査
